# Provenance and licensing

Soviet Simulator is a hard fork of **Egregoria** by Pâris Douady
(`@Uriopass`) and contributors — <https://github.com/Uriopass/Egregoria>.

**Fork point:** upstream commit `ae65c857948a905120474cf93b96dd51cec6d5f6`
(VERSION 0.6.1, dated 2025-06-02), taken on 2026-08-22.

Upstream is dormant; this is a hard fork, not a tracking branch. There is no
merge discipline with upstream and no expectation of contributing back.
