# Mermaid rendering

**Kind:** reference
**Authority:** operational
**Status:** active
**Owner:** project lead
**Last verified:** 2026-08-28

Mermaid diagrams are Markdown source. The configured `mdbook-mermaid` preprocessor renders them
in the HTML book. Use diagrams only when they make a relationship clearer than short prose.

## Current renderer

- Preprocessor: `mdbook-mermaid` 0.17.1.
- Browser bundle: Mermaid 11.6.0, MIT license.
- Source: <https://github.com/mermaid-js/mermaid/releases/tag/v11.6.0>.
- Bundle SHA-256: `eefea253bed9655e838eb874ff955c46872f982a8e26290c1dd2982ddc0a4703`.
- Initializer: generated by `mdbook-mermaid install .`; MPL-2.0 source file with the local strict
  security setting.
- Initializer SHA-256: `eba19ea34b48c7ba292be803ee4082db3a709ef275161fcf30d3ecce0086d85c`.

Use basic flowcharts unless a later Mermaid version is installed and tested. Give every diagram an
`accTitle` and `accDescr`. Do not use inline styles or Mermaid initialization directives.

## Update procedure

1. Replace the bundle from an identified upstream release.
2. Record its version, source URL, license, and SHA-256 here.
3. Run `python3 scripts/check_docs.py` and `mdbook build`.
4. Inspect a rendered diagram in both configured themes.
