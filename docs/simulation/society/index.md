## What belongs here

This section covers people, households, daily life, labour, workplace institutions, and the
social-reproduction loop that connects them to the planned economy. Every page separates what
the charter and draft specs commit to, what the design proposes, what the code does today, and
what remains an open question.

The production side of the economy, goods movement, and physical infrastructure live elsewhere.
The boundary: if a mechanism changes because an enterprise builds a canteen or a citizen queues
at a shop, it belongs here; if it changes because a truck is loaded or a pipe is laid, it does
not.
